# SCGC Altium Library

## Overview

A professional component library developed for Altium Designer, containing reusable symbols, footprints, 3D models, and design resources for hardware development projects.

This repository was created to improve design speed, consistency, and quality across multiple PCB projects.

---

## Contents

### Schematic Libraries

* Component symbols
* Parameterized parts
* Reusable circuit elements

### PCB Footprint Libraries

* Standard SMT packages
* Through-hole packages
* Connectors
* Power components
* RF / communication parts
* Custom footprints

### 3D Models

* Mechanical models for PCB visualization
* Assembly checking support
* Enclosure fit validation

### Design Resources

* Frequently used parts
* Organized component database
* Reusable engineering assets

---

## Purpose

This library helps to:
